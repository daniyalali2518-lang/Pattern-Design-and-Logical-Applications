# Pattern-Design-and-Logical-Applications
This assignment is focusing on Pattern Design, Logical Thinking and Mathematical Operations, uses C-programming.

# Overview of Programming Practices

This assignment explores different programming techniques through practical C language exercises. It focuses on creating star and number patterns using nested loops and applying conditional statements to perform mathematical calculations. It also introduces BMI calculation and classification through logical conditions. These exercises help develop programming logic, accuracy, and problem-solving skills.

1. Star Rectangle Pattern:
   Uses nested for loops and spacing to print a rectangular star pattern.
2. Hollow Pattern Design:
   Uses nested loops and conditional statements to create a structured hollow star pattern.
3. BMI Calculator:
   Calculates Body Mass Index using weight and height, then classifies the result through if-else conditions.
4. Binary Number Triangle:
   Uses nested loops and the modulus operator to generate a triangular pattern of alternating zeros and ones.
5. Conditional Star Pattern:
   Uses nested loops and arithmetic conditions to print a structured star pattern.
6. Inverted and Increasing Star Pattern:
   Uses nested loops to generate increasing and decreasing star arrangements.
